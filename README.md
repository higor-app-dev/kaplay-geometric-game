# Shape Survivor 🦖

Jogo mobile feito com **KaplayJS** — apenas formas geométricas, sem sprites.

- 🔺 **Triângulo azul** → você!
- ⭕ **Círculos vermelhos** → obstáculos — desvie!
- ⬜ **Quadrados amarelos** → colete para pontuar

👉 [Jogar agora](https://higor-app-dev.github.io/kaplay-geometric-game/)

🎮 Controles mobile: toque e arraste
⌨️ Desktop: setas / WASD
